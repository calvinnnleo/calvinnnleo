### 🤖 About Me

Welcome to my GitHub profile! I am an **AI / ML Engineer & Data Scientist** passionate about building intelligent machine learning systems, GenAI pipelines, predictive modeling, and modern web applications.

- 🤖 **Focus**: AI / ML Engineering, Data Science & GenAI Integration.
- 💡 **Specialization**: Time-Series Forecasting, LLM APIs (Gemini/Grok), Explainable AI (SHAP/LIME) & Data Pipelines.
- 🌱 **Currently Building**: Scalable Machine Learning Pipelines, FastAPI Services & MLOps with Docker.
